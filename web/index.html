      How this page is built

      Nobody updates it by hand. A scheduled pipeline pulls fresh data every 6 hours, models and tests it, and publishes the result.

      1. ExtractPython pulls hourly air quality and weather for 8 cities from the Open-Meteo API, with retries and an idempotent monthly overwrite.
      2. LandRaw data is stored as Parquet files, partitioned by city and month, on a dedicated data branch.
      3. Transformdbt on DuckDB builds staging, intermediate and mart models from the lake.
      4. TestData tests check keys, value ranges, relationships and freshness. A failed test stops the publish.
      5. PublishMarts are exported to JSON and committed; Vercel redeploys this page.

      Source code on GitHub

      Data: Open-Meteo (CAMS global air-quality model, about 40 km resolution). These are modelled values for each city, not readings from a single street sensor, so local peaks can be higher.
